<h2>About</h2>

<p>
  NetBreaker is an open-source project currently under development.
  It focuses on reverse proxying, load balancing, and server management,
  with the goal of providing a way to manage and route traffic between
  backend services.
</p>

<h2>Current Status</h2>

<p>
  NetBreaker is actively being developed. Its architecture, features,
  and internal components may change as development progresses.
</p>

<p>
  It is not yet a stable release.
</p>
